# Result
- Files can be uploaded to the web version and a corpus selected for it. Duplicate sentences can be deleted.
- Sentence ID alone or with the text can be used for a sentence to be identified in a corpus.
- IDs, forms or lemmas of a sentence can be changed by an annotator, but not the text of a sentence.
- SVG format should be used for displaCy graphs, instead of the png format and image manipulation.
- Some adjustments may need to be done regarding the interannotator agreement design as a result of the discussion. Büşra said a sentence is usually annotated by one person and another person checks for consistency in the entire treebank at the end.
